# 아동 인구·시설 행정동 분석

## 실행

프로젝트 루트에서:

```powershell
python -m pip install -r requirements-dev.txt
python data_analyze/child_population/analyze_child_population.py
```

Shapely를 포함한 분석 의존성은 루트의 `requirements-dev.txt`에서 관리합니다.
원본은 수정하지 않고 실행별 결과를 data/processed/child_population/YYYYMMDD_HHMMSS 에 저장합니다.

## 결과 파일

- mapped/: 모든 CSV와 보호구역 상세 시트에 원본 필드, 행정동 코드, 매핑 상태를 추가.
- normalized/: 보호구역 XLSX의 모든 시트를 별도 CSV로 보존. 서로 겹치는 시트는 중복 합산하지 않음.
- source_audit.csv: 원본 SHA-256, 인코딩, 행 수, 매핑 수, 실제 집계 수, 시점·실패 사유.
- dong_reference_20261001.csv: 사용한 427개 행정동 코드/이름.
- population_panel_2021_2025.csv: 1세 단위 자료에서 0~5/0~12/0~17세 합산.
- population_growth_all_periods.csv: 연간 및 3년 증감률. 누적 3년 변화이지 연평균 성장률 아님.
- current_facilities_by_dong.csv: 현재 파일의 적격 매핑 기록만 집계.
- analysis_current_facilities_vs_2024_2025_growth.csv: 분석에 사용한 1행=행정동 데이터.
- feature_dictionary.csv: 피처의 출처와 해석 한계.
- method_comparison.csv: Spearman/Pearson/Kendall, 부분 순위 상관, n, 탐색적 p/BH q.
- report.html, correlations.png: 전처리와 결과 비교.

## 중요한 해석 조건

1. 인구 파일명에는 연도만 있으므로 동일한 월/기준일인지 원 제공처에서 확인해야 합니다.
2. 시설은 주로 2026년, 인구는 2025년까지입니다. 현재 시설과 과거 변화의 후향적 탐색이지 미래 예측이 아닙니다.
3. 2021~2025 모두 현재와 같은 코드가 있는 지역으로 제한하지만, 같은 코드의 경계 조정까지 보장하지 않습니다.
4. 인구는 영유아(0~5세)를 주 분석으로 삼고 나머지 연령 범위는 민감도 비교입니다. 출생·연령 이동·이사가 섞인 변화입니다.
5. per1000은 모두 2024년 전체 주민 인구 기준입니다. 0~5세 1천명당 시설 수와 혼동하지 마세요.
6. 병원은 병원 인허가 자료이며 의원 전체/소아과 전체가 아닙니다. 지역아동센터도 어린이집·보육정보센터가 아닙니다.
7. 병원 X/Y의 좌표계가 원 파일에 명시되지 않아 추정 변환하지 않습니다. 정확한 CRS를 확인하면 공간 매핑을 보완할 수 있습니다.
8. 주소만 있는 시설은 법정동→행정동이 유일한 경우에만 연결합니다. 일대다 대응은 지오코딩 또는 상세 지번 대응이 필요합니다.
9. 통학구역 파일에는 도형·좌표가 없어 행정동 매핑을 완료할 수 없습니다. ID에 대응하는 공간 도형을 추가 확보해야 합니다.
10. 관광지는 한국어(ko/kr/kor) 기록만 집계합니다. 번역 중복을 줄이지만 미매핑으로 과소집계될 수 있습니다.
11. 전국 자료는 서울 밖 기록을 제외합니다. 같은 파일 안의 시설 중복은 식별자 우선으로 제거하되 다른 파일의 동일 시설은 서로 다른 지표로 유지합니다.
12. 낮은 매핑률의 병원·음식점·관광지는 quality_flag로 표시합니다. 해당 상관을 피처 채택이나 가중치로 바로 사용하지 마세요.
13. 정원/면적 누락은 0으로 채우지 않아 시설 개수와 표본 수가 다를 수 있습니다. 보고서의 n을 함께 비교하세요.
14. 공원면적은 대표좌표 소재 동에 공원 전체 면적을 귀속한 보조 지표이며 실제 동 경계 내 공원면적이 아닙니다.
15. 구 고정효과·초기 인구 규모·아동 비율을 보정한 부분 상관도 주택 공급 등 누락 변수와 역인과는 해결하지 못합니다.
16. 공간적 의존성과 데이터 품질 때문에 p/q값은 확정적인 유의성 판정이 아닙니다. 상관계수를 최종 점수 가중치로 변환하지 않습니다.

## 다음 연도 아동 인구 증감률 분석·학습

`data/raw/아동/아동 데이터/핵심`의 2021~2025년 1세 단위 인구를 정답 원천으로 고정하고,
연도별 행정동 특징을 결합해 다음 연도 로그 증감률을 분석·학습하려면 다음을 실행합니다.

```powershell
python ml/training/train_child_population_growth.py
```

영유아(0~5세), 초등(6~11세), 중등(12~14세), 고등(15~17세)을 각각 학습합니다.
2021~2023년 leave-one-year-out 교차검증으로 후보를 비교하고 2024→2025 전환은 시간 외
테스트로만 사용합니다. 특징 순위도 개발기간에서만 계산합니다. 결과는 실행 시각별
`artifacts/child_population_growth/`에 저장되며 `report.html`에 원천 선별, 목표 정의,
연관도, 모델 비교, 선정·보류 판단과 한계가 기록됩니다. 공유 MLflow가 설정된 개발환경에서는
`child-population-next-year-growth` Experiment에도 같은 평가자료와 모델 파일을 기록합니다.

## 주택공급·학교와 아동 인구 변화의 준인과 점검

주택 입주자료와 학교의 실제 개교일을 이용한 인과 가능성 감사는 다음 명령으로 실행합니다.

```powershell
python data_analyze/child_population/analyze_housing_school_causality.py
```

서로 다른 발표 시점의 입주예정물량 파일은 중복 합산하지 않습니다. 최신 2024년 말 발표본의
2024년 별첨 사업만 고정하고, 주민 1,000명당 입주 세대와 2024→2025 아동 인구 변화의
관계를 직전 추세·아파트 전세 보증금/㎡ 변화에 더해 자치구별 2023년 출생률,
2023→2024 출생 변화, 학교급별 2023년 학급당 학생 수를 통제해 탐색합니다. 학교의 공식
정원·과밀 판정 대신 학생 수/학급 수를 사전 수용압력 대체지표로 사용합니다. 5,000회
순열 검정과 입주 전 2022→2023 추세 위약 검정을 함께 기록하며, 효과 검정이 유의해도
위약검정이 유의하면 인과 후보로 채택하지 않습니다.

출생자료는 2021~2025 동별 신고자료의 자치구 소계를 사용합니다. 월별 주택 착공실적은
서울 전체 합계만 있어 자치구 효과 추정에서는 제외하고 감사표에 사유를 남깁니다. 현재도
서울 전체 `인구이동(연령별_월별)`은 2021년 1월~2026년 8월의 이동 방향을 설명하는 데
사용합니다. 별도로 KOSIS `시군구/성/연령(5세)별 이동자수(DT_1B26001)` 2021~2025
대량통계 CSV를 `data/raw/아동/인구이동_자치구_연령별/`에 확보했습니다. 이를 서울 25개
자치구×연도×0~4·5~9·10~14·15~19세의 총전입·총전출·순이동으로 집계하고, 2024년
공급 뒤 완전한 사후연도인 2025년 순이동률을 별도 결과변수로 검정합니다. 2023년
순이동률은 공급 전 위약검정과 통제에 사용합니다. 자치구 25개와 실제에 가까운 입주 관측
1개년이라는 한계 때문에 결과가 유의해도 무작위 인과효과로 확정하지 않습니다. 결과는
`artifacts/child_population_causality/` 아래 실행 시각별 `report.html`과 CSV에 저장됩니다.

## 유아 인프라 연관·방향성·예측 분석

서울 25개 자치구의 2021~2025 실제 어린이집 정원·현원, 유치원, 출생, 0~4세 이동,
주택 및 0~5세 인구를 결합하려면 다음을 실행합니다.

```powershell
python data_analyze/child_population/analyze_infant_infrastructure.py
```

연령대별 인구증가율 대신 실제 지역 이동을 주 목표로 분석하려면 다음 명령을 사용한다.
자치구 단위 0~4세·5~9세·10~14세·15~19세 순전입률을 분석하고, 2024→2025
시간 외 검증 및 2025년 특징 기반 2026년 예측을 생성한다.

```powershell
python ml/training/train_child_net_migration.py
```

결과는 `artifacts/child_net_migration/<실행시각>/`에 저장된다. 순전입 자료가
자치구 단위이므로 행정동으로 복제하지 않으며, 15~19세에는 대학 진학·취업·입대
이동이 섞인다는 제한을 보고서와 함께 확인해야 한다.

자치구·연도 고정효과로 인프라 변화와 다음 해 유아인구 증가의 방향성을 점검하고, 반대
방향도 함께 검정합니다. 예측은 2021~2023년을 학습 자료로, 2024년 특징에서 발생한
2024→2025 증가율을 시간 외 검증으로 사용합니다. 결과와 모델은 실행별
`artifacts/infant_infrastructure_analysis/`에 저장됩니다. 회귀 문제이므로 성능은 분류
정확도 대신 MAE, RMSE, R²를 주 지표로 보고하며 증감 방향 적중률은 보조지표로 제공합니다.
