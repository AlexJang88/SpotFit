# 아동 인구·시설 행정동 분석

## 실행

프로젝트 루트에서:

```powershell
python -m pip install -r data_analyze/requirements.txt
python -m pip install -r data_analyze/child_population/requirements.txt
python data_analyze/child_population/analyze_child_population.py
```

추가 패키지는 공간 매핑용 Shapely입니다. 기존 서버 requirements는 변경하지 않습니다.
원본은 수정하지 않고 실행별 결과를 data/processed/child_population/YYYYMMDD_HHMMSS 에 저장합니다.

## 결과 파일

- mapped/: 모든 CSV와 보호구역 상세 시트에 원본 필드, 행정동 코드, 매핑 상태를 추가.
- normalized/: 보호구역 XLSX의 모든 시트를 별도 CSV로 보존. 서로 겹치는 시트는 중복 합산하지 않음.
- source_audit.csv: 원본 SHA-256, 인코딩, 행 수, 매핑 수, 실제 집계 수, 시점·실패 사유.
- dong_reference_20261001.csv: 사용한 427개 행정동 코드/이름.
- population_panel_2021_2025.csv: 1세 단위 자료에서 0~5/0~12/0~17세 합산.
- population_growth_all_periods.csv: 연간 및 3년 증감률. 누적 3년 변화이지 연평균 성장률 아님.
- current_facilities_by_dong.csv: 현재 파일의 적격 매핑 기록만 집계.
- analysis_current_facilities_vs_2024_2025_growth.csv: 분석에 사용한 1행=행정동 데이터.
- feature_dictionary.csv: 피처의 출처와 해석 한계.
- method_comparison.csv: Spearman/Pearson/Kendall, 부분 순위 상관, n, 탐색적 p/BH q.
- report.html, correlations.png: 전처리와 결과 비교.

## 중요한 해석 조건

1. 인구 파일명에는 연도만 있으므로 동일한 월/기준일인지 원 제공처에서 확인해야 합니다.
2. 시설은 주로 2026년, 인구는 2025년까지입니다. 현재 시설과 과거 변화의 후향적 탐색이지 미래 예측이 아닙니다.
3. 2021~2025 모두 현재와 같은 코드가 있는 지역으로 제한하지만, 같은 코드의 경계 조정까지 보장하지 않습니다.
4. 인구는 영유아(0~5세)를 주 분석으로 삼고 나머지 연령 범위는 민감도 비교입니다. 출생·연령 이동·이사가 섞인 변화입니다.
5. per1000은 모두 2024년 전체 주민 인구 기준입니다. 0~5세 1천명당 시설 수와 혼동하지 마세요.
6. 병원은 병원 인허가 자료이며 의원 전체/소아과 전체가 아닙니다. 지역아동센터도 어린이집·보육정보센터가 아닙니다.
7. 병원 X/Y의 좌표계가 원 파일에 명시되지 않아 추정 변환하지 않습니다. 정확한 CRS를 확인하면 공간 매핑을 보완할 수 있습니다.
8. 주소만 있는 시설은 법정동→행정동이 유일한 경우에만 연결합니다. 일대다 대응은 지오코딩 또는 상세 지번 대응이 필요합니다.
9. 통학구역 파일에는 도형·좌표가 없어 행정동 매핑을 완료할 수 없습니다. ID에 대응하는 공간 도형을 추가 확보해야 합니다.
10. 관광지는 한국어(ko/kr/kor) 기록만 집계합니다. 번역 중복을 줄이지만 미매핑으로 과소집계될 수 있습니다.
11. 전국 자료는 서울 밖 기록을 제외합니다. 같은 파일 안의 시설 중복은 식별자 우선으로 제거하되 다른 파일의 동일 시설은 서로 다른 지표로 유지합니다.
12. 낮은 매핑률의 병원·음식점·관광지는 quality_flag로 표시합니다. 해당 상관을 피처 채택이나 가중치로 바로 사용하지 마세요.
13. 정원/면적 누락은 0으로 채우지 않아 시설 개수와 표본 수가 다를 수 있습니다. 보고서의 n을 함께 비교하세요.
14. 공원면적은 대표좌표 소재 동에 공원 전체 면적을 귀속한 보조 지표이며 실제 동 경계 내 공원면적이 아닙니다.
15. 구 고정효과·초기 인구 규모·아동 비율을 보정한 부분 상관도 주택 공급 등 누락 변수와 역인과는 해결하지 못합니다.
16. 공간적 의존성과 데이터 품질 때문에 p/q값은 확정적인 유의성 판정이 아닙니다. 상관계수를 최종 점수 가중치로 변환하지 않습니다.
