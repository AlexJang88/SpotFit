# 아동 인프라 데이터 수집기

## 현재 자동 수집 범위

현재 공식 API 서비스명과 응답 구조를 검증한 서울시 어린이집 데이터를 자동 수집합니다.
API 키 없이 임의 URL을 호출하거나 웹 화면을 크롤링하지 않습니다. 결과는
`data/raw/child_infrastructure_collected/YYYYMMDD`에 원본 JSON과 SHA-256 manifest로 저장합니다.

프로젝트 루트의 `.env`에 키를 저장합니다. `.env`는 Git에 커밋하지 않습니다.

```dotenv
SEOUL_OPEN_DATA_API_KEY=발급받은_서울열린데이터광장_인증키
```

그다음 프로젝트 루트에서 실행합니다.

```powershell
python scripts/child_infrastructure/collect_child_infrastructure.py
```

## 분석에 필요한 데이터 영역

| 영역 | 주요 지표 | 현재 상태 | 행정동 결합 |
| --- | --- | --- | --- |
| 인구 | 연령별 아동·전체 인구, 증감 | 기존 2021~2025 파일 보유 | 행정동 코드 |
| 보육 | 어린이집 수·정원·현원·교직원·국공립 여부 | 자동 수집 | 좌표 공간조인/주소 |
| 교육 | 유치원·초중고·학원 | 학교 기존 파일, 나머지 추가 출처 필요 | 좌표 공간조인 |
| 돌봄 | 지역아동센터·다함께돌봄 | 지역아동센터 기존 파일 | 좌표 공간조인 |
| 의료 | 소아청소년과·병원·보건소·야간진료 | 병원 기존 파일 | 좌표/주소, 진료과 필터 |
| 안전 | 보호구역·CCTV·비상벨·아동 보행사고 | 일부 기존 파일 | 좌표 공간조인 |
| 놀이·녹지 | 공원·어린이공원 수와 면적 | 공원 기존 파일 | 좌표/폴리곤 공간조인 |
| 문화·체육 | 도서관·체육시설·아동 프로그램 | 추가 출처 필요 | 좌표 공간조인 |
| 환경 | 미세먼지·소음·폭염·침수 | 추가 출처 필요 | 측정소 보간/격자 중첩 |
| 주거 | 아파트 규모·가격·면적 | 기존 2021~2025 실제 분기 관측 보유 | 행정동 코드 |
| 교통 | 정류장·역·보행 접근성 | 추가 출처 필요 | 좌표 공간조인/네트워크 |

유치원 API는 좌표 없이 주소만 제공하므로 `VWORLD_API_KEY` 같은 서버용 지오코딩 키가 추가로
필요합니다. 브라우저 도메인 제한 키와 서버 호출 키가 다를 수 있으므로 실제 키를 저장소에
커밋하지 않고 `.env`에서 관리합니다. 지오코딩 결과는 주소·좌표·응답일·성공 여부를 캐시하여
같은 주소에 대한 호출을 반복하지 않습니다.

## 결합·학습 가능성

현재 스냅샷만으로는 행정동별 **현재 점수**와 횡단면 연관 분석은 가능합니다. 그러나 3년 뒤
점수나 아동 인구를 예측하려면 각 설명변수의 과거 연도별 값이 필요합니다. 현재값을 과거 모든
연도에 복제하면 데이터 누수이므로 금지합니다. 시설 데이터는 수집일별 스냅샷을 계속 누적하고,
현재 스냅샷의 인가·폐업일로 과거 상태를 복원하지 않습니다. 과거 시점에 실제로 공표·관측된
파일이나 API 응답만 시계열 학습에 사용합니다.

행정동 결합 우선순위는 `행정동 코드 → 좌표와 경계 공간조인 → 도로명주소 지오코딩`입니다.
동 이름만 결합하면 같은 이름과 법정동/행정동 차이 때문에 오류가 발생할 수 있습니다.

권장 학습 행은 `기준연도 × 행정동`이며, 시설 원시 개수뿐 아니라 아동 1,000명당 공급량,
정원 충족률, 최근접 거리, 도보권 내 시설 수를 생성합니다. 평가는 무작위 행 분할 대신 연도
기준 검증과 행정동 그룹 검증을 함께 사용합니다.

### 학습에 반드시 추가로 고려할 항목

- 시설과 인구의 동시점 상관은 인과효과가 아니다. 특징은 최소 1년 시차를 두고 미래 인구를 예측한다.
- 현재 시설 스냅샷을 2021~2025 각 연도에 복제하지 않는다.
- 시설 수와 함께 정원·현원·운영시간·국공립 여부 및 접근거리를 사용한다.
- 원시 개수, 대상 아동 1,000명당 공급량, 면적당 밀도를 각각 비교한다.
- 대단지 입주, 주택가격·전월세, 출생, 전입·전출, 전체 인구, 소득을 혼란변수 후보로 추가한다.
- 인접 행정동 시설도 이용할 수 있으므로 경계 500m/1km 버퍼와 공간가중 특징을 비교한다.
- 행정동 경계 개편은 해당 연도 경계로 환산하고 코드 체계를 데이터 사전에 명시한다.
- 극단값은 삭제하지 말고 원인 확인 후 로그변환·RobustScaler·윈저화 민감도 결과를 비교한다.
- 검증은 시간 순서 분할과 자치구/행정동 그룹 분할을 함께 사용한다.
- 최종 점수 가중치는 단순 상관계수가 아니라 시간 외 검증 성능과 안정성을 기준으로 결정한다.

## 학교 데이터: 실제 관측 2021~2026 패널

`data/raw/school`에는 2021년부터 2026년까지 매년 4월 1일 기준 학교별 일람표가 있다.
따라서 2026년 학교 현황을 과거에 복사하거나 중간 연도를 추정하지 않고도 같은 계절의
6개년 실제 관측 패널을 만들 수 있다.

학교 원본에는 행정동 코드가 없으므로 `data/raw/rnaddrkor_seoul.txt`의 공식 도로명주소와
정확히 일치하는 주소만 행정동 코드·명칭으로 연결한다. 동 이름 문자열 추측이나 유사 주소
매칭은 잘못된 행정동을 만들 수 있어 사용하지 않는다.

```powershell
python scripts/child_infrastructure/build_observed_school_panel.py
```

결과는 `data/interim/child_school_observed`에 생성된다.

| 파일 | 용도 |
| --- | --- |
| `observed_school_panel_2021_2026.csv` | 연도·행정동별 학교급별 학교/학생/교원/학급 수 |
| `school_address_mapping_2021_2026.csv` | 학교별 주소와 행정동 매핑 상세 |
| `school_mapping_quality.csv` | 연도별 성공·실패 건수 검증 |
| `unmatched_school_addresses.csv` | 주소 누락·과거 주소 등 자동 매핑하지 않은 검토 대상 |

현재 원본 기준 12,933행 중 12,842행(99.30%)이 매핑됐다. 미매핑 91행은 값을 임의로
대체하지 않는다. 학습용 주 패널에는 2021~2025년을 사용하고, 2026년은 최신 특성 또는
시간 외 평가용으로 분리하는 것이 안전하다.

이 작업으로 해결되는 것은 학교·유치원의 연도별 공급 및 이용 규모이다. 구체적으로 학교급별
학교 수, 학생 수, 교원 수, 학급 수를 실제 관측값으로 사용할 수 있다. 반면 어린이집,
지역아동센터, 공원, 의료시설, 도서관, 안전시설, 체육 프로그램 등은 별도의 과거 공표자료가
없다면 여전히 현재 스냅샷이다. 실제 관측 패널과 아래의 사건 날짜 기반 복원 패널은
`observed`와 `reconstructed`로 구분하여 동일한 신뢰도로 취급하지 않는다.

## 사건 날짜 기반 시설 시계열 복원

시설의 인가·설치·폐업 날짜로 과거 존재 여부를 복원하기로 한 실험에서는 다음 명령을
사용한다.

```powershell
python scripts/child_infrastructure/build_reconstructed_infrastructure_panel.py
```

결과는 다음 위치에 생성된다.

```text
data/interim/child_infrastructure_reconstructed/
├─ reconstructed_infrastructure_panel_2021_2026.csv
└─ reconstruction_quality.csv
```

복원 대상은 어린이집(인가·휴지·폐지일), 병원(인허가·휴업·폐업일), 공원(지정고시일),
CCTV(설치연월), 안전비상벨(설치연도)이다. 모든 주소는 도로명주소의 공식 행정동을 우선
사용하고, 실패한 행만 좌표 공간조인으로 보완한다. 행정안전부 10자리 코드와 프로젝트
통계경계 8자리 코드는 단순 절단하지 않고 자치구·행정동 명칭 대응으로 변환한다.

현재 목록에서 이미 삭제된 시설은 복원할 수 없으므로 생존편향이 있다. 공원·CCTV·비상벨은
폐지·철거일이 없어 현재 남은 시설만 과거로 누적한다. 어린이집 정원·현원, 병원 병상·의료인,
진료과목 같은 현재 속성은 과거에 복사하지 않는다. 비교 실험용 소아청소년과 수만
`current_attribute_backfill`이라는 위험 표시를 컬럼명에 붙인다.

현재 복원 결과의 행정동 매핑 품질은 다음과 같다.

| 자료 | 원본 행 | 행정동 매핑 | 한계 |
| --- | ---: | ---: | --- |
| 어린이집 | 9,495 | 8,882 | 현재 목록 기반, 과거 정원·현원 없음 |
| 병원 | 930 | 834 | 의원급 의료기관 별도 필요 |
| 공원 | 1,786 | 1,780 | 폐지 이력 없음 |
| CCTV | 59,750 | 59,708 | 철거 이력 없음 |
| 안전비상벨 | 26,315 | 26,299 | 철거 이력 없음 |

지역아동센터는 설치·폐지일, 공공도서관은 개관·폐관일, 체육 프로그램은 프로그램 시작·종료
이력이 현재 원본에 없어 복원 패널에 넣지 않는다. 해당 자료는 현재 점수에만 사용한다.
