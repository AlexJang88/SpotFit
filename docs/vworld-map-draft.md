# 지도 UI 초안

기존 React/Vite의 HomePage를 MAP-01~09 더미 화면으로 교체합니다.
Leaflet은 지도 UI 엔진이며 배경지도는 VWorld WMTS만 사용합니다.

## 실행

frontend에서 `npm install`, `npm run dev`를 실행합니다.
frontend/.env.local에 `VITE_VWORLD_API_KEY=발급받은키`를 설정하고 Vite를 재시작하세요.
키가 없으면 다른 지도 서비스로 우회하지 않고 격자 배경의 더미 지도를 표시합니다.
VWorld에서 실제 접근 도메인/서비스 URL을 허용해야 합니다.
브라우저용 VITE 변수는 번들 및 네트워크 요청에 노출되므로 비밀키처럼 취급하면 안 됩니다.
관리자용 비밀키는 넣지 마세요. 개발/운영 도메인 제한을 설정하세요.
Docker 개발에서도 Vite 프로세스에 해당 변수가 전달되거나 .env.local이 마운트되어야 합니다.
정적 배포는 빌드 시 환경변수 주입 후 재빌드해야 합니다.

## 범위와 가정

- 가격: 만원/㎡, 예측기간: 1/3년, 고정 기준시점: 2026년 10월.
- 예측은 고정 변동률을 적용한 예시. 서비스 모델이나 기존 모델 산출물을 사용하지 않음.
- 시 1개, 구 5개, 행정동 7개의 예시만 검색 가능.
- 지도 줌 <11 시, 11~12 구, 13 이상 행정동. 수동 선택은 자동 모드를 해제.
- 구·행정동은 2026-10-01 공개 경계, 서울 외곽은 같은 동 경계의 합집합이다.
- 가격 버튼 클릭 시 해당 구·행정동만 녹색 강조, 카드 닫기 시 강조 해제.
- 시설명·좌표는 가상 데이터. 육아환경은 25개 구 가상 지표로 선택 기반 점수를 계산한다.
- 사이드바 기본 숨김. 양육환경 모드를 누르면 사이드바가 열리고 구 단위로 전환한다.
- 점수 선택·추천 상세는 [점수 기능명세서](../spot_fit_scoring_spec.md)의 CARE-01~10을 따른다.
- 추천 순위는 25개 구, 지도 가격 마커는 기존 5개 구 예시만 제공한다.
- 상세보기는 데이터 출처/예측 근거를 연결할 UI 자리로, 실제 근거를 꾸며내지 않음.
- VWorld 인증키 없이 UI·지역 검색·팬/줌·필터를 사용할 수 있지만 배경 타일은 검증 불가.

## 확인 항목

1. 키 미설정 안내, 시/구/동 선택 및 자동 줌 전환.
2. 지역 검색 → 지도 이동, 가격 버튼 클릭 → 요약 카드/영역 강조, 검색 실패 안내.
3. 네 가지 표시 모드 전환 → 라벨/범례 일치. 녹색 영역은 점수 등급이 아닌 선택 표시.
4. 1/3년 변경 → 예상가격·변동률·환산가격 변경.
5. 시설 토글 → 시설 레이어 표시/숨김.
6. 상세보기 → 키보드 Escape/닫기로 종료.
7. 390px 모바일 및 데스크톱 화면에서 목록과 지도 접근 가능.
8. 유효 VWorld 키 및 등록 도메인에서 배경 타일과 출처 표시 확인.
9. 9개 평가 항목·중요도 변경 → 추천 목록과 구 지도 점수/카드 동기화.
10. 마지막 체크박스 해제 차단, 추천 목록 클릭 시 계산 상세, 시/동 점수 미지원 안내.
