# 연령대별 서울 자치구 안전점수 데이터 감사

기준일: 2026-10-30

## 대상과 점수 영역

| 대상 | 연령 | 핵심 영역 |
|---|---:|---|
| 영유아 | 0~5세 | 보행·차량, 보육·놀이시설, 응급의료, 생활환경·재난 |
| 초등학생 | 6~12세 | 통학·스쿨존, 학교생활, 유해환경, 범죄보호, 시설·재난 |
| 중·고등학생 | 13~18세 | 학교폭력, 야간귀가·대중교통, 범죄, 유해환경, 상담·보호 |
| 성인 | 19~64세 | 범죄, 교통, 야간보행, 화재·재난, 응급대응 |

고령자 지표는 이번 범위에서 제외한다. 모든 발생 건수는 가능한 경우 해당 연령 인구 또는 노출 인구를 분모로 사용한다.

## 모델에 반드시 필요한 결과값

시설 수만으로는 안전성을 학습할 수 없다. 다음 연도 실제 피해율을 Y로 사용해야 한다.

1. 영유아: 0~5세 교통·생활안전 사고율
2. 초등학생: 6~12세 보행·스쿨존 사고율과 학교폭력 피해응답률
3. 중·고등학생: 13~18세 교통·학교폭력·범죄 피해율
4. 성인: 19~64세 교통사고·범죄·화재 인명피해율

공개자료에서 연령과 자치구가 동시에 제공되지 않으면, 전체 자치구 결과를 Y로 쓰고 연령대별 점수에는 연령 특화 노출지표를 별도로 적용한다. 이 경우 결과를 `연령별 실제 피해 예측`이라고 표현하지 않는다.

## 아직 인증 또는 신청이 필요한 자료

### 공공데이터포털 서비스키

- TAAS 교통사고 상세 또는 연령별 교통사고
- 서울특별시 어린이놀이시설 정보(OA-23006 연결 서비스)
- 소방청 화재·구조·구급 시군구 통계

프로젝트 환경변수의 `DATA_GO_KR_API_KEY`는 정상 인식됐다. 다만 공공데이터포털의 키는 API별 활용신청이 별도로 필요하다. `15124519` 활용신청 승인 후 아래 명령으로 서울 자료를 수집한다.

```powershell
python scripts/safety/collect_playgrounds.py
```

### 학교알리미·EDSS

- 최근 3년 학교폭력 실태조사 결과는 학교알리미에서 학교별 수집 가능
- 3년 이전 자료와 추가 학교 식별자료는 에듀데이터서비스(EDSS) 심사 신청 필요

### 직접 파일 다운로드

- 침수흔적도·재해위험지구 공간파일
- 서울소방서·119안전센터·구조대 과거 위치 파일

## 점수 설계 원칙

- 시설이 많으면 무조건 안전하다고 두지 않는다.
- 사고·피해율은 낮을수록 높은 점수를 부여한다.
- CCTV·경찰·보호구역은 위험 때문에 설치됐을 수 있으므로 예방 인프라와 실제 결과를 분리한다.
- 연도별 모델은 미래 자료가 섞이지 않도록 롤링 시간 검증을 사용한다.
- 서울 25개 자치구 상대 A~E 등급과 절대 0~100점을 함께 제공한다.
