## 이번에 추가 확보한 자료

`data/raw/아동/전연령_교육인프라_공식통계/서울시_25개자치구_학원교습소_20261026.json`

- 서울 열린데이터광장의 25개 자치구별 `학원 교습소정보` Open API를 모두 수집했다.
- 25개 자치구, 25개 서비스, 총 25,479행이다.
- 학원명, 개설일, 등록일, 등록상태, 정원, 분야, 교습계열, 교습과정, 주소를 포함한다.
- 수집 시점 제공 목록은 전부 `개원` 상태다. 따라서 2026년 현재 학원 접근성에는 사용할 수 있지만, 폐원시설이 빠진 상태에서 개설일만 이용해 2021~2025 과거 시설수를 복원하면 생존편향이 생긴다.
- 재수집 명령은 `python scripts/child_infrastructure/collect_academies.py`다.

공식 메타데이터도 다음과 같이 저장했다.

- `meta_20795.json`: 학급당 학생 수(구별)
- `meta_20799.json`: 학생변동상황(전입·전출)
- `meta_21183.json`: 사설학원 및 독서실

학급당 학생 수는 이미 보유한 학교별 실제 관측으로 직접 계산할 수 있어 중복 수집이 필수는 아니다. 학생변동과 사설학원 연도 통계는 공식 제공 대상임을 확인했지만, 새 데이터 허브의 해당 통계 미리보기 응답에는 데이터 행이 없었다. 현재 학원 원본은 별도의 자치구 Open API로 확보했다.

## 아직 추가로 필요한 실제 과거 패널

다음 자료가 없더라도 인구 예측 모델은 만들 수 있지만, 교육·돌봄 인프라의 인과효과를 설명하려면 필요하다.

1. 행정동 또는 학교별 초등돌봄·늘봄 교실 정원과 실제 이용자 수(2021~2025)
2. 폐원시설을 포함한 학원·교습소 연도 말 전체 스냅샷(2021~2025)
3. 자치구×연도×학교급 학생 전입·전출 원자료
4. 중학교 졸업자의 고등학교 유형별 진학 자료와 고등학교 학업중단 자료
5. 행정동×연도 실제 준공·입주 세대와 입주시점

위 자료가 없는 Feature는 현재 스냅샷을 과거에 복제하지 않는다. 그렇게 하면 미래정보 누수가 생겨 예측 정확도가 과대평가된다.

## 현재 가능한 범위

- 행정동별 1년 예측: 네 그룹 모두 가능
- 자치구별 연관분석: 네 그룹 모두 가능
- 학교 인프라와의 시간 방향성: 학교 패널이 실제 관측이므로 가능
- 학원 인프라의 2021~2025 인과분석: 현재 스냅샷만으로는 불가
- 3년 직접 예측: 2021→2024와 2022→2025 두 전환뿐이므로 시나리오 수준으로 제한
