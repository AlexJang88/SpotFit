기준일: 2026-10-23

| 인접동 시설 미반영 | 후속 단계에서 500m·1km 버퍼 및 인접행정동 공간가중 특징으로 비교 예정 |
| 상관관계의 인과 오해 | 가중치는 단순 상관계수 대신 시간 외 검증 성능·안정성으로 선정하도록 규칙화 |

## 추가 확보 우선순위

1. **2021~2025 일평균 대기환경 파일**: PM10·PM2.5·오존의 자치구 연평균과 나쁨 일수를 생성한다. 서울 열린데이터광장 OA-2220 파일을 연도별 원본 그대로 저장한다.
2. **전입·전출·출생 자료**: 단순 아동 수보다 `다음 연도 아동 순유입률` 타깃을 만들기 위해 필요하다.
3. **공동주택 입주·세대·면적 자료**: 상권분석서비스의 2021~2025 실제 4분기 관측값으로 혼란을 보정한다.
4. **주택 매매·전월세 가격**: 주거비 수준과 변화율을 법정동에서 행정동으로 면적/주택 가중 배분한다.
5. **아동 보행사고**: 발생 건수 대신 아동 인구와 도로 길이 대비 사고율을 사용한다.
6. **다함께돌봄·육아종합지원센터**: 지역아동센터와 별도 지표로 유지한다.
7. **의원급 소아청소년과·야간휴일진료**: 병원급 데이터만으로 의료 접근성을 대표하지 않는다.
8. **버스정류장·지하철역·보행 네트워크**: 직선거리와 실제 도보시간을 구분한다.

## 모델에 넣는 방법

현재 점수는 2025 인구 분모와 2026 시설 스냅샷으로 만들 수 있지만, 이는 미래예측 모델의
훈련 패널이 아니다. 미래예측은 다음 형태로 구성한다.

```text
X(t) = t년 말 인프라 + 주거 + 환경 + 인구 구조 + 전입·전출
Y(t+1) = 다음 연도 아동 인구 증감률 또는 순유입률
Y(t+3) = 3년 뒤 아동 인구 증감률 또는 순유입률
```

동일 행정동의 시간 누수를 막기 위해 마지막 1~2개 연도를 테스트로 두고, 자치구 그룹 검증을
추가한다. 성능 비교는 평균 예측 기준선, 선형 정규화 모델, Random Forest/Extra Trees,
Gradient Boosting 계열을 같은 분할로 수행한다. 공간가중 특징은 원본 특징 모델보다 시간 외
성능이 개선될 때만 채택한다.
