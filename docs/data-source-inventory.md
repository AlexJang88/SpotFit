# SpotFit 확보 데이터 및 출처 총정리

- 작성 기준일: 2026-11-05
- 조사 범위: `data/raw`, `data/interim`, `data/processed`
- 현재 보유 규모: `.gitkeep` 제외 103개 파일, 약 530.71MB
- 출처 판정 근거: 실제 파일명과 컬럼, 수집·전처리 코드, 기존 데이터 감사 문서

## 1. 문서 읽는 법

| 출처 확인 수준 | 의미 |
|---|---|
| 확인 | 파일 또는 수집 코드에 기관명·데이터명·URL이 기록되어 있음 |
| 높은 확률 | 컬럼 구조와 처리 코드가 공식 데이터와 일치하지만 원본 매니페스트가 없음 |
| 확인 필요 | 파일은 있으나 원 다운로드 URL이나 수집 기록이 충분하지 않음 |

`interim`과 `processed` 파일은 대부분 원천 데이터의 정제·집계·결합 결과다. 따라서 아래 출처표에서는 같은 원천에서 만들어진 파생 파일을 별도 외부 출처로 세지 않는다.

### 4.2 데이터 계보

```text
국토교통부 실거래가 계열 원자료
  ├─ 아파트·빌라 매매 원자료
  │   └─ 법정동+지번 → 행정동 매핑
  │       └─ 취소·주소 불일치 거래 제외 및 파생변수 생성
  │           └─ 행정동별_*_매매_최종.csv
  └─ 서울 열린데이터광장 전월세 연도별 파일(2021~2026)
      └─ 연도별 병합·중복 확인
          └─ 법정동+지번 → 행정동 매핑 및 정제
              └─ 행정동별_*_전월세_최종.csv
```

매매 최종 파일의 컬럼과 처리 코드는 국토교통부 실거래가 자료 구조와 일치한다. 다만 현재 저장소에는 해당 최종 파일의 직접 원본과 수집 매니페스트가 없으므로, 재현성을 위해 원본 파일명·다운로드 일시·URL·SHA-256을 추가로 남겨야 한다.

## 8. 추가 수집 코드가 있으나 현재 `data/raw`에 없는 자료

다음 자료는 수집·전처리 코드 또는 분석 산출물은 존재하지만, 현재 조사한 `data/raw`에는 원본이 없거나 별도 위치에서만 사용된 흔적이 있다.

- 서울 데이터 허브 자치구 월별 대중교통 이용 자료(2024~2025)
- Open-Meteo ERA5-Land 자치구별 일별 기상자료(2010~2025)
- 소음·진동, 안전센터, 행정민원, 유흥·단란주점 등 생활안전 보조자료
- 아동 인프라: 어린이집, 유치원, 학교, 병원, 공원, 도서관, 지역아동센터, 학원 등
- 상권분석서비스: 매출, 상주·직장·유동인구, 점포, 집객시설 등

이들은 프로젝트 코드나 분석 결과에 사용 흔적이 있더라도, 원본 보존 여부를 별도로 확인하기 전에는 “현재 원본 확보 완료”로 분류하지 않는다.

## 9. 출처·재현성 보완이 필요한 항목

1. 아파트·빌라 매매 최종 파일의 직접 원본과 수집 매니페스트가 없다.
2. `서울시_물가상승률_최종.xlsx`의 공식 통계표명과 URL이 기록되어 있지 않다.
3. `어린이교통사고_2010_2025.xlsx`는 TAAS 자료로 보이지만 원 다운로드 화면·조건 기록이 없다.
4. 범죄 CSV의 공식 데이터셋 URL, 다운로드일, 경찰서→자치구 매핑 규칙을 문서화해야 한다.
5. 자동차등록대수는 TAAS 「시군구별 자동차등록대수」로 확인했으며, 갱신 시 농기계·건설기계 확정 여부와 다운로드일을 매니페스트에 추가해야 한다. CCTV는 서울 열린데이터광장 OA-2734·OA-21097로 확인했으며, 갱신 시 공개파일 기준일과 연도별·누적값의 의미를 기록해야 한다.
6. 생활안전의 제조업 종사자, 안전예산, 안전신문고, 응급처치 교육인원은 아직 원본이 없다.
7. `interim`·`processed` 결과에는 원본 SHA-256과 생성 스크립트 버전을 연결한 공통 매니페스트가 필요하다.

## 10. 권장 출처 표기 문구

> 부동산 매매 자료는 국토교통부 실거래가 공개시스템 자료를 기반으로 하며, 전월세 자료는 국토교통부 실거래 자료를 연계한 서울 열린데이터광장 「서울시 부동산 전월세가 정보」를 사용하였다. 교통사고 자료는 한국도로교통공단 교통사고분석시스템(TAAS)의 서울시 자치구별 통계를 사용했으며 고속국도를 제외하였다. 교통안전 보조지표에는 KOSIS, 국민건강보험공단, 질병관리청 지역사회건강조사, 서울특별시, 서울경찰청, 행정안전부 및 공공데이터포털 자료를 사용하였다.
